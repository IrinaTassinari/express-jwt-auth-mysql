Как Это Работает:
1. Сервер запускается через app.js.
2. app.js подключает роуты, например /auth/....
3. Роут /auth/register или /auth/signin вызывает функцию в контроллере.
4. Контроллер работает с моделью authUser.js.
5. Модель через Sequelize обращается к таблице auth_users в MySQL.
6. Для логина после проверки пароля создаётся JWT.
7. Для защищённых маршрутов middleware читает токен и проверяет его.


Что Делает JWT Middleware
Когда пользователь идёт на защищённый маршрут:
        GET /auth/profile
        Authorization: Bearer <token>
middleware:
1. берёт заголовок Authorization
2. достаёт токен
3. проверяет токен через jwt.verify(...)
4. если токен валиден, кладёт данные пользователя в req.user
5. передаёт управление дальше

Тогда контроллер profile может вернуть:
id
email
username
из токена или из БД
